<h2>v0.0.0-beta.3 — Custom Panorama & Button Animation</h2>

<h3>Features</h3>
<ul>
<li><strong>Custom 360° Panorama</strong>: Set 6 images (<code>panorama_0.png</code> to <code>panorama_5.png</code>) that Minecraft renders as a rotating 3D cube. Use <code>"background.type": "custom_panorama"</code> and list your files under <code>background.panorama.files</code>.</li>
<li><strong>Button Slide Animation</strong>: Buttons now slide in from the left by default with a smooth ease-out curve. Configure via <code>buttonAnimation</code>: <code>type</code> (<code>"slide_right"</code>, <code>"none"</code>), <code>duration</code>, <code>offset</code>.</li>
<li><strong>External Image Loading</strong>: Panorama faces and backgrounds can be loaded from absolute file paths or resource locations.</li>
</ul>

<h3>Changes</h3>
<ul>
<li>Config file renamed from <code>skd_menu_menu.json</code> to <code>skd_menu.json</code> (cleaner name, no repetition).</li>
</ul>

<h3>Notes</h3>
<blockquote>If you have an existing <code>config/skd_menu_menu.json</code>, rename it to <code>config/skd_menu.json</code> or the mod will generate a fresh default config.</blockquote>
