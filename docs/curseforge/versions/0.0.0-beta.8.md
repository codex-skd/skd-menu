<h2>v0.0.0-beta.8 — Custom Title & Button Rework</h2>

<h3>Features</h3>
<ul>
<li><strong>Custom Title Image</strong>: New <code>title.type</code> config (<code>"image"</code>, <code>"vanilla"</code>, <code>"hidden"</code>). Default <code>"image"</code> shows a custom logo at top-left. Set <code>"vanilla"</code> to restore the original Minecraft title.</li>
<li><strong>Smart Overlays</strong>: Image overlays with <code>"x": -1, "y": -1</code> auto-place at top-right corner.</li>
<li><strong>Button Defaults List</strong>: Use <code>buttons.defaults</code> array to configure per-button hide and position. Custom buttons without coordinates auto-place below defaults.</li>
</ul>

<h3>Notes</h3>
<blockquote>If you have an existing <code>config/skd_menu/menu.json</code> with the old button structure, the mod will use defaults. Migrate to the new <code>buttons.defaults</code> format for full control.</blockquote>
