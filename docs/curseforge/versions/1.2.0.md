<h2>v1.2.0 - Self-installing early loading theme</h2>

<h3>Features</h3>
<ul>
<li><strong>Automatic early display setup</strong>: on first run the mod now installs its branded NeoForge early loading theme by itself &mdash; writes <code>config/fml/theme-skd.json</code> plus its sprites (background image, top-left banner, white bordered progress bar), and configures <code>config/fml.toml</code> (early window enabled, theme id <code>skd</code>, 16:9 window so the background fills the screen).</li>
</ul>

<h3>Notes</h3>
<blockquote>The early loading window is shown before mods load, so the theme takes effect from the second launch. No manual config is needed anymore &mdash; drop the JAR in <code>mods/</code> and it configures itself.</blockquote>

<p><strong>JAR</strong>: <code>skd_menu-26.2-neoforge-1.2.0.jar</code></p>
