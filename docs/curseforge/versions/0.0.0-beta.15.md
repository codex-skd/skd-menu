<h2>v0.0.0-beta.15 — Button Images, hideText, Hover Feedback</h2>

<h3>Fix</h3>
<ul>
<li>Fixed HTTP(S) image URLs never actually applying to buttons/backgrounds/logos — the download was registering the texture off the render thread and silently failing.</li>
</ul>

<h3>Features</h3>
<ul>
<li>New <code>hideText</code> option for buttons: shows only the image, no label.</li>
<li>Buttons with a custom image now highlight on hover/focus and darken when disabled, like vanilla buttons.</li>
<li>New default button layout with a bundled button image applied to all buttons out of the box.</li>
</ul>
