<h2>v1.2.4 - NeoForge 26.2.0.57 compatibility fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Startup crash on NeoForge 26.2.0.57</strong>: the Mods button on the title screen referenced <code>net.neoforged.neoforge.client.gui.ModListScreen</code>, which NeoForge relocated to <code>net.neoforged.neoforge.client.gui.modlist.ModListScreen</code> (and replaced its public constructor with a static <code>create(Screen)</code> factory). This caused a <code>NoClassDefFoundError</code> in <code>Minecraft.&lt;init&gt;</code>, crashing the game before it could even open the main menu.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Recompiled against NeoForge <code>26.2.0.57</code> (bumped from <code>26.2.0.45-beta</code>).</li>
<li><code>TitleScreenMixin</code> now calls <code>ModListScreen.create(screen)</code> from the new package.</li>
</ul>

<blockquote>Required update if you're running NeoForge 26.2.0.57 or newer — the game will not start with this mod on older builds without it.</blockquote>
