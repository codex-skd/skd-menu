<h2>v0.0.0-beta.14 — Crash Fix</h2>

<h3>Fix</h3>
<ul>
<li>Fixed a client crash that could happen with the default button slide-in animation when a button's configured width was too narrow for its label. The animation no longer slides a button past the left edge of the screen, and a 20px minimum button width is now enforced as an extra safeguard.</li>
</ul>
