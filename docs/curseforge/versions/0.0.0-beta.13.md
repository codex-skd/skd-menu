<h2>v0.0.0-beta.13 — Percentage-Based Positioning</h2>

<h3>Changes</h3>
<ul>
<li>Position fields (x/y) for logos, title, image overlays, default buttons, and custom buttons are now a percentage (0-100) of the current window size instead of a fixed pixel value. A custom position now stays proportionally in place when the window is resized, instead of ending up out of place at a different window size.</li>
<li>Added a new <code>width</code> option to default buttons, letting you set a custom pixel width for any of them.</li>
</ul>
