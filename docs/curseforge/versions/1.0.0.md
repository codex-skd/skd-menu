<h2>v1.0.0 - First stable release (Minecraft 1.21.1)</h2>

<p>First stable release of SKD Menu for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>
(Java 21). It consolidates the <code>0.0.0-beta.1</code> &rarr; <code>0.0.0-beta.5</code> line with
no further code changes. This build has been running in a full modded-server pack.</p>

<h3>What the 1.21.1 line brought</h3>
<ul>
<li><strong>API port of the stable 26.2 line (1.2.4)</strong>: 10 classes, client mixins into the
title screen, no dependencies. Full title-screen customization: custom / panorama / colour /
animated background with the breathing zoom, corner logos + title image, per-button
reposition / hide / custom buttons / button images, and image overlays &mdash; all through a JSON
config.</li>
<li><strong>Generic third-party button control</strong> (<code>buttons.thirdParty</code> in
<code>menu.json</code>): buttons other mods add to the vanilla title screen (Create, Quark,
Configured, Catalogue, &hellip;) are detected by non-vanilla class package and can be repositioned,
resized or hidden, stacked in a left column by default.</li>
<li><strong>Custom loading screen removed on 1.21.1</strong> (<code>beta.4</code>): its textured
draws did not render reliably during a server resource-pack reload on large modpacks (a
<code>GuiGraphics</code> batching interaction with another client mod). NeoForge's vanilla loading
screen is used there instead; the title-screen customization is unchanged. The 26.2 branch keeps
the custom loading screen.</li>
<li>Removed the dead <code>friends</code> default button (no Friends feature on 1.21.1).</li>
<li><strong>Spanish (<code>es_es</code>) locale</strong> bundled: all 9 keys.</li>
</ul>

<h3>Notes</h3>
<blockquote>Client-side only. Verified: <code>./gradlew clean build</code> is green;
<code>./gradlew runClient</code> loads with the title-screen mixin applied, 0 FATAL; verified
in-game (custom title screen intact, server join/disconnect shows the vanilla loading screen).
Shares this CurseForge project with the 26.2 line &mdash; pick the file that matches your Minecraft
version.</blockquote>
