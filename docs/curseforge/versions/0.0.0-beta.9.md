<h2>v0.0.0-beta.9 — Stalking Dragons Logo & Title Animation</h2>

<h3>Features</h3>
<ul>
<li><strong>Custom Logo</strong>: Default title image replaced with Stalking Dragons themed logo.</li>
<li><strong>Title Animation</strong>: New <code>title.animated</code> option enables a smooth breathing/pulse zoom effect. Configure range with <code>animRange</code> (0.05 = 5%) and speed with <code>animSpeed</code> (1.5 cycles/sec).</li>
<li><strong>Knowledge Graph</strong>: Graphify extraction added for AI-assisted development.</li>
</ul>
