<h2>v0.0.0-beta.1 — Initial Beta Release</h2>

<h3>Features</h3>
<ul>
<li><strong>Custom Main Menu</strong>: Replace the vanilla title screen with a fully customizable layout via JSON config.</li>
<li><strong>Background Types</strong>: Choose between panorama (vanilla), static image, solid color, or animated frame sequences.</li>
<li><strong>Custom Images</strong>: Set any image from your resource packs or mod assets as the menu background.</li>
<li><strong>Animated Backgrounds</strong>: Cycle through a sequence of frame images at a configurable frame rate (pseudo-video).</li>
<li><strong>Button Positioning</strong>: Reposition every vanilla button (singleplayer, multiplayer, options, quit, language, accessibility, mods) using configurable X/Y coordinates.</li>
<li><strong>Hide Buttons</strong>: Remove any vanilla button from the menu.</li>
<li><strong>Custom Buttons</strong>: Add new buttons with actions: execute commands, open singleplayer/multiplayer/options screens, open URLs, or quit the game.</li>
<li><strong>Image Overlays</strong>: Render images at any position on the screen with configurable width, height, and scale.</li>
<li><strong>JSON Config</strong>: All settings are stored in <code>config/skd_menu_menu.json</code>, auto-generated on first launch.</li>
</ul>

<h3>Technical Details</h3>
<ul>
<li>Built for <strong>NeoForge 26.2</strong> (Minecraft 26.2).</li>
<li>Uses the new extraction-based rendering pipeline (<code>GuiGraphicsExtractor</code>).</li>
<li>Mixin-based approach for maximum compatibility (no <code>ScreenEvent.Opening</code> dependency).</li>
<li>Client-side only — safe for servers.</li>
</ul>
