<h2>v0.0.0-beta.1 - Port to Minecraft 1.21.1</h2>

<p>First beta of SKD Menu for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). API port of the stable 26.2 line (1.2.4) &mdash; same feature set.</p>

<h3>About this build</h3>
<ul>
<li><strong>API port</strong> of the 26.2 source (10 classes, 3 client mixins) to the 1.21.1 client render API: <code>GuiGraphicsExtractor</code> &rarr; <code>GuiGraphics</code> (the 26.2 "extract render state" pass is gone &mdash; the title-screen / loading-overlay injects retarget the 1.21.1 <code>render</code> method); <code>net.minecraft.util.ARGB</code> &rarr; <code>FastColor.ARGB32</code>; <code>RenderPipelines</code> &rarr; plain <code>GuiGraphics</code> blit/fill; the 26.2 8-arg stretching blit &rarr; a pose-scaled blit helper; <code>Identifier</code> &rarr; <code>ResourceLocation</code>; the removed Friends screen &rarr; Realms directly; a handful of screen-constructor and <code>Minecraft</code> field/method renames.</li>
<li><strong>Feature set</strong>: custom / panorama / colour / animated background with the breathing zoom, corner logos + title image, per-button reposition / hide / custom buttons / button images, image overlays, the restyled loading screen + progress bar, and the FML early-window theme.</li>
</ul>

<h3>Notes</h3>
<blockquote>Client-only menu / loading-screen mod, no gameplay content. Verified: <code>./gradlew build</code> OK; <code>./gradlew runClient</code> loads &mdash; both client mixins apply into <code>TitleScreen</code> / <code>LoadingOverlay</code>, all injects are recognized, the mod initializes (early-display theme installed, "client setup complete"), 0 FATAL, clean shutdown. Not yet reviewed visually on screen.</blockquote>
