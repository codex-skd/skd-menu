<h2>v0.0.0-beta.11 — Fixed Zoom Background, Corner Logos &amp; Button Images</h2>

<h3>Features</h3>
<ul>
<li>Fixed single background image with a smooth zoom ("breathing") effect, replacing the rotating-frame slideshow as the default.</li>
<li>Aspect-ratio preserving background fit — no more distortion on small or unusual window sizes.</li>
<li>Two fixed corner logos (top-left and top-right), each independently configurable.</li>
<li>Background, logos, title, overlays, and button images can now be loaded from a mod asset, a local file, or an external URL.</li>
<li>Default button list is now pre-filled with all 7 recognized IDs and automatic positioning out of the box.</li>
<li>Custom image support for any button, plus a global fallback image for all buttons.</li>
<li>Full configuration reference added to the mod's documentation.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Custom buttons without both an explicit X and Y position are now hidden instead of auto-stacking below the default buttons.</li>
<li>Center title is hidden by default to avoid showing a leftover placeholder image.</li>
<li>Added the "Realms" button and the NeoForge dev/test "TW" badge to the recognized default button IDs; both are hidden by default, fixing overlaps with other repositioned buttons.</li>
</ul>
