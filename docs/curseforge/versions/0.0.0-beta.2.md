<h2>v0.0.0-beta.2 - Third-party title-screen buttons</h2>

<p>SKD Menu can now take over the buttons that <strong>other mods</strong> add to the title screen, and the dead <code>friends</code> button left over from the 26.2 line is gone.</p>

<h3>Added</h3>
<ul>
<li><strong>Third-party button control</strong> (<code>buttons.thirdParty</code> in <code>menu.json</code>). Any button another mod adds to the vanilla title screen &mdash; Create, Quark, Configured, Catalogue, or anything else &mdash; is detected generically (any widget whose class is not <code>net.minecraft.</code> or <code>com.skd.menu.</code>) and can be repositioned, resized or hidden.</li>
<li>By default those buttons are stacked in a <strong>vertical column on the left</strong> (<code>stackX</code> / <code>stackY</code> / <code>stackGap</code> / <code>stackFromBottom</code>, percentage-based like the rest of the config).</li>
<li>Per-button <code>entries</code> are <strong>auto-generated</strong> into <code>menu.json</code> the first time each button is seen, keyed by a slug from the owning mod (<code>create</code>, <code>quark</code>, &hellip;; <code>-2</code> / <code>-3</code> suffixes if one mod adds several). Set both <code>x</code> and <code>y</code> to <code>&gt;= 0</code> to pin a button and take it out of the stack; <code>hide: true</code> removes it.</li>
</ul>

<h3>Removed</h3>
<ul>
<li>The dead <strong><code>friends</code></strong> default button. Minecraft 1.21.1 has no Friends feature, so the mod had been generating a non-functional button that rendered the raw <code>gui.friends.open</code> key. Removed from the defaults, the mixin and the config docs. An existing <code>menu.json</code> that still lists <code>friends</code> is simply ignored.</li>
</ul>

<h3>Technical</h3>
<ul>
<li>New <code>ThirdPartyButtons</code> class &mdash; a client <code>ScreenEvent.Init.Post</code> subscriber at <code>EventPriority.LOWEST</code>. Third-party mods add their buttons on that event, after <code>TitleScreen.init()</code> (after <code>TitleScreenMixin</code> runs), so their handling is a separate low-priority pass over <code>Screen#children()</code>.</li>
</ul>

<h3>Notes</h3>
<blockquote>Client-only menu mod, no gameplay content. Verified: <code>./gradlew clean build</code> OK. The third-party button pass has not yet been reviewed visually on screen with those mods installed.</blockquote>
