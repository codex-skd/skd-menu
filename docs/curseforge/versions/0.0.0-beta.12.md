<h2>v0.0.0-beta.12 — Language-Independent Default Buttons</h2>

<h3>Fix</h3>
<ul>
<li>Default buttons (singleplayer, multiplayer, options, quit, etc.) no longer depend on the game's language to be repositioned, hidden, or given a custom image. Previously the mod matched the vanilla button by its translated on-screen text, which silently broke in any non-English locale. It now hides every vanilla title-screen button and rebuilds it using Minecraft's own translation keys, so the label stays correctly localized while positioning and customization work in any language.</li>
</ul>

<h3>Changes</h3>
<ul>
<li>Added "Friends" as a recognized default button.</li>
<li>Removed the IDE/dev-only "TW" test badge from the recognized list — it never appears in a real build.</li>
<li>Realms is no longer hidden by default.</li>
</ul>
