<h2>v1.1.0 - Custom loading screen</h2>

<h3>Features</h3>
<ul>
<li><strong>Custom loading screen</strong>: the vanilla Mojang loading overlay is replaced with a branded screen driven by the new <code>config/skd_menu/loading.json</code> &mdash; static background image (same as the main menu, configurable, with HTTP(S) URL support), top-left banner and top-right mod logo (both hideable), and a custom progress bar.</li>
<li><strong>Custom progress bar</strong>: an ornate frame (<code>bar_track</code>) with a procedural violet&rarr;magenta gradient fill drawn <em>behind</em> the frame (the fill only shows through the transparent groove), cropped to the current progress with an optional soft glow.</li>
<li><strong>Early loading screen theme</strong>: support for theming the NeoForge early display (during mod loading) &mdash; background image, banner, and white bordered progress bar via <code>config/fml/theme-*.json</code> + sprites.</li>
</ul>

<h3>Config</h3>
<ul>
<li>New <code>config/skd_menu/loading.json</code> controls: <code>background</code> (image/color), <code>banner</code> (top-left), <code>logo</code> (top-right), <code>bar</code> (position, size, track texture, gradient colors, glow).</li>
<li>Menu keeps its existing <code>menu.json</code>; the banner/logo hide options apply to both menu and loading screens.</li>
</ul>

<h3>Assets &amp; cleanup</h3>
<ul>
<li>Removed unused images (duplicate mod icon, unused animation background frames).</li>
<li>Added <code>bar_track.png</code> (custom progress bar frame).</li>
</ul>
